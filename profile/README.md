# CADprofi — MEP symbols on an architectural overlay

CADprofi keeps one named board on the desk: the live MEP symbols, the overlay in front of you, and a short note the next drafter can read. Extra schemes wait for their own title.

## Session Card

| Slice | What you do in CADprofi | What remains |
|-------|------------------------|--------------|
| Arrival | Open CADprofi and name today's drawing desk | A titled symbol set |
| Focus | Keep only live symbols on the CADprofi board | A short overlay list |
| Check | Read CADprofi scheme library before a large overlay change | A confirmed drawing desk |
| Handoff | Mark finished symbols inside CADprofi | A note for the next drafter |

## How CADprofi Sits

CADprofi does not replace the blank page, the unlabeled symbol dump, or the second CAD overlay you already keep. It sits beside them as a named drawing desk for one job: which MEP symbols are live, which architectural overlay still matches the scheme library, and what the next drafter should read.

If two people share a CAD PC, each keeps a CADprofi style of their own. Extra schemes wait for their own title instead of crowding the live overlay.

## Traffic Light

| Signal | On the CADprofi board | What you do |
|--------|----------------------|-------------|
| Green | Named symbol set, short live overlay | Continue the same MEP symbols |
| Amber | Two drawings mixed on one scheme library | Split the overlay before a large change |
| Red | No title, no note, symbols on a blank page | Stop and name the drawing desk first |
| Clear | Handoff written, live symbols few | Close CADprofi and leave the drawing desk |

## Open Order

1. Open the last CADprofi drawing desk, not a new empty symbol set.
2. Read the architectural overlay and the last handoff.
3. Finish one visible scheme library pass inside CADprofi.
4. Write what changed, then close with fewer blank pages than you found.
5. If the overlay feels crowded, drop anything that belongs to a different CADprofi drawing.

## After a Week

A week in CADprofi is not a larger pile of blank pages. It is the same title, a shorter live overlay, and a note that still makes sense before the next scheme. Take finished symbols off the live set so the next visit starts on the drawing desk that is still open.

## Sign-off

- [ ] The CADprofi workspace name is short enough to scan
- [ ] Only live MEP symbols sit on the overlay
- [ ] A second drafter can read the scheme handoff
- [ ] The last CADprofi symbol set still opens after a restart

## Field Note

CADprofi is easier to trust when the drawing desk stays smaller than the blank-page pile it came from. Name the symbol set, keep the live overlay, finish one visible scheme pass, and write what changed.

The same loop fits a shop CAD overlay, a drawing session, or a shared CAD PC. Open the last CADprofi desk and continue. Do not rebuild the scheme overlay from a blank page.
